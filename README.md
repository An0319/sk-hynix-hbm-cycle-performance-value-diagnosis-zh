# SK海力士深度研究——HBM周期王者的价值诊断与格局推演

一份基于公开数据的全球存储芯片产业格局与投资价值深度分析报告。

## 关于本项目

这份报告是我作为独立研究者完成的全栈战略分析项目，结合产业格局推演与财务价值诊断，对 SK 海力士在 HBM 时代的竞争地位与投资价值进行系统分析。

**我的角色**：独立完成从数据采集、框架搭建、战略推演、财务分析到报告撰写的全流程。

**核心内容**：

- 全球存储产业格局全景（4重壁垒分析：寡占、资本、物理、认证）
- 5方竞争主体立场分析（海力士领跑、三星失位、美光追赶、英伟达依赖、中国缓图）
- 3大趋势研判（技术迭代、需求膨胀、周期波动）
- 2026-2028 三轨情景推演（基准/乐观/悲观）
- ROIC-WACC 价值创造诊断（+38.5% 超额回报分析）
- 9条可证伪预测与投资框架
- 33+ 数据源的完整审计链

**方法工具**：定量数据整理与可视化 + 结构化战略分析框架（利益相关方分析、结构分析、趋势判断）+ ROIC-WACC 价值创造诊断框架

**数据来源**：海力士官方财报、DART披露、TrendForce、券商研报、权威媒体报道等 33+ 公开数据源，所有数据均可通过参考文献链接验证。
